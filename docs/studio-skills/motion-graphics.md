# Motion graphics

标识：`motion-graphics`

规划可编辑的文字、数据与图形动画。

## 适用场景

需要卖点卡片、数字展示、标题动画或信息图动效。

## 输入资料

- 需要表达的信息与品牌视觉
- 画幅、时长和镜头背景
- 真实数据与可用图形

## 执行步骤

1. 确定信息层级并简化每屏内容。
2. 逐元素定义出现时刻、停留时长、运动方向和退场方式。
3. 描述布局、文字、图形及与镜头的配合。
4. 标注可编辑属性与字幕阅读时间。

## 输出内容

- 动效时间轴
- 元素与可编辑属性清单
- 制作说明

## 质量要求

- 数字都有资料来源
- 动效不遮挡主体或妨碍阅读
- 提供计划，不宣称已经渲染动画
