# Reference breakdown

标识：`reference-breakdown`

拆解用户提供的参考描述，提取可复用的节奏、镜头结构和表达方式。

## 适用场景

将参考广告的结构转化为自己的创作计划。

## 输入资料

- 参考脚本、镜头描述或可读取的资料
- 自己的产品、目标与时长

## 执行步骤

1. 标注参考的开场、铺垫、卖点、证明和 CTA。
2. 整理镜头顺序、时长、转场及文字与声音的配合。
3. 区分可以借鉴的结构与需要替换的品牌专属内容。
4. 根据自己的产品给出改编提纲；没有可读取的内容时请求镜头描述。

## 输出内容

- 参考结构表
- 可借鉴要素及需要替换的内容
- 自己的版本提纲

## 质量要求

- 不宣称已观看只有链接的参考视频
- 不编造参考内容
- 改编围绕自己的产品和品牌
